INDEPENDENT IMAGE WATERMARK ANALYSIS

Inspect an image.
Understand the evidence.

Upload an image for an automatic local scan. The prototype checks for its own experimental hidden marker, searches for repeated visible text, and reports file metadata and a SHA-256 hash. No Google account or external detector is required.

PNG, JPG, JPEG or WEBP · Max 25 MB · Local processing

01 / VISIBLE

Visible text watermark scan

OCR and image preprocessing search for repeated text that may be a watermark. Faint, stylized or diagonal text can be missed, so candidates require visual review.

02 / HIDDEN

Experimental hidden marker

Checks for a small custom marker embedded by this prototype. It does not detect arbitrary invisible watermarks or proprietary schemes.

03 / EVIDENCE

Image details and integrity

Displays dimensions, format, available EXIF fields and SHA-256 hash. Metadata can be missing or edited; a hash identifies exact file bytes, not authorship.

04 / EVALUATION

Transformation experiments

Embed the demo marker, then test crop, resize, brightness, contrast and JPEG compression. Results help measure this marker’s limitations.

Scientific limitation: this version does not classify images as AI-generated or human-created. Absence of a detected watermark is not evidence that an image is human-made. AI-origin classification will require a separately evaluated model and labelled test dataset.
